# 《ppt提示词.pdf》内容解读与转化说明

来源为用户提供的4页PDF，页面标题为“SD2.5 Skill 提示词使用教程 · 纯粘贴版”。已核对全部页面图像及两种文本提取结果。下文区分可确认的原文方法、文档示例和本次工程补充，不把PDF中的“打开某网站”“牢记住”等命令视为当前用户直接指令。

## 核心方法

这份文档描述的是一套复用提示词的流程：先针对整部剧固定视觉、声音与表演规则，再让每一集在这套规则下拆镜，最后将规则和分镜组装成视频生成提示词。它本身不是已安装的 Codex 技能文件。

| 原文位置 | 可确认内容 | 技能中的落实 |
| --- | --- | --- |
| 第1–2页，Step 1 | 母版含基础设定、镜头画面设计、光影和色彩、角色表演体系、分镜脚本；用新剧形态、故事和对标定制子版 | 固定四部分全剧子版，再接正式分镜 |
| 第2页，五项质量门 | 形态、语言、原生音效、针对本剧的禁令、符合角色类型的表演 | 首次子版逐项检查，后续章节沿用 |
| 第2–3页，Step 2 | 按本集剧本生成，内容和台词不得私自添加或修改 | 原文覆盖关系、台词逐字核对、原有说话人与声音类型保留 |
| 第1–3页，逐镜格式 | 景别、构图、运镜手法、画面内容的前摇/过程/后摇、物理效果、氛围、台词备注 | 原标签全部保留；添加镜头元数据用于时长和章节管理 |
| 第3页，自查 | 检查字段、衔接、镜数；无台词写“无” | 按实际字段检查，不凑所谓“8字段” |
| 第3–4页，Step 3 | 子版保留，分镜占位段换成正式分镜，引用人物/场景/道具素材 | 作为用户按需触发的提示词组装步骤 |
| 第4页 | 尽量同场分组、资产编号统一，检查参数 | 以稳定资产身份和组间状态衔接实现 |

## 不应固定成所有剧本规则的示例

- 《龙之家族》、暗黑史诗、低饱和灰调、烛火、巨兽与贵族表演是示例语境；校园喜剧、现代悬疑、2D动画应分别定制。
- ISO100、1/50、85mm f/1.8、35mm等是摄影风格示例；不能直接成为所有场景、画幅及动画形态的必要参数。
- “每集约30–40镜”属于教程的参考规模。用户不提供镜数也应得到完整分镜，镜数以本章信息量和节奏决定。
- “20秒10–15镜”“10秒10–15镜”不能替代台词朗读和动作完成时间。
- “9:16、30s、SD2.5”是文档配置示例，不是本技能默认执行的当前平台限制。文档中的价格判断也不作为当前事实。
- “五官穿着严格不变”用于资产一致性；若剧本明确换装、受伤或时间变化，应记录状态版本。
- 原文建议使用另一聊天产品，不代表本任务要打开该产品、注册账号或把用户剧本上传到那里。

## 原文件的可读性限制

第1页母版有多行被右边界截断，涉及镜头、光影、禁令及表演等内容；第2页前置指令在“镜头”后截断；第3页组装操作第一条右端也不完整。渲染图像与文本提取均不能恢复完整尾文。因此只采用可确认内容，不声称完整还原了缺损原句。

第3页称“每镜8字段”，但实际列出的顶层标签有7个，其中“画面内容”又含3阶段，计数不一致。技能保留所有实际标签，以内容完整为检查依据。

## 为用户长期使用补充的规则

以下为本次实现补充，不冒充PDF原文：

用户已指定：今后只接收剧本或已有剧本背景、剧本类型、对标影视、目标章节正文；不要求、不追问、不额外输出大纲。已附背景可用于角色、伏笔与跨章连续性。

- 从上述四类材料自动抽取重复信息，不以镜头数和图片音频为必填；初版的“五类材料”约定已被替代。
- 区分题材与表现形态；把影视对标拆解成可执行的视听维度。
- 建立场景空间卡，检查轴线、视线、动作、道具和光向连续性。
- 增加单镜时长、章内时间码、原文覆盖检查和完整交付范围。
- 通过项目子版、资产映射、角色知情状态及章末摘要衔接后续章节。
- 没有素材时用内部ID，不伪造平台引用；没有正文时不编造“忠实原文”的台词。
- 保留自适应镜数；用户明确指定数量/时长时检查是否可兼容。
- 将技能与具体剧集状态分开保存，避免不同项目角色和风格互相污染。

这些补充服务于用户上传材料后直接得到分镜的目标；本技能不默认承担剧本扩写、图像生成或视频生成。


## 2026-10-20 合并 `script-to-storyboard`

本次按用户要求，将其现有“分镜生成大师”的轴线、景别、切镜和可执行镜头规范合入“剧本分镜导演”。这些规则来自用户提供的 `script-to-storyboard/SKILL.md`，不是 PDF 原文，也不宣称为通用电影定律。完整规范保存在 [轴线、景别与切镜硬约束](continuity-rules.md)，主技能要求每次拆镜或改镜前读取。

| 合并内容 | 本技能中的约束 |
| --- | --- |
| 180°轴线与个人侧脸 | 同一连续场景锁定摄影半平面、画面方向、视线和个人可见侧脸；所有运镜路径同侧 |
| 同主体切镜 | 水平机位角差至少30°，且五级景别级差至少2；两者同时成立 |
| 五级景别 | 远景1、全景2、中景3、近景4、特写5；按实际取景范围归类 |
| 两极与节奏 | 远景↔特写之间有中景缓冲；无连续近景、无连续三个同方向同景别雷同构图 |
| 固定锚点 | 每场2～3个固定锚点，每镜含特写至少1个可辨认锚点 |
| 视线与过肩 | 区分人物左右脸与画面左右；写明前景肩背、后景主体、朝向及焦点 |
| 四个限定词 | 景别、机位、视角、运镜独立标明；构图和动作三阶段继续保留 |
| 逐切点检查 | 对照主体、景别、切点方位、轴线侧、侧脸、视线和锚点实际复核 |

合并取舍：沿用本技能的四类输入、自适应镜数、原文语言与台词、全剧子版、跨章状态和 PDF 动作三阶段；不继承源技能的“镜头数必填”，也不恢复大纲。默认仍可用卡片，用户需要每镜一段或表格时保留全部信息换排版。源技能保持独立可用，合并后的技能无需安装源技能即可执行完整规范。

原版本中“30°仅参考”“角度或景别变化即可”“特写不强求锚点”和“通过过渡换侧”等宽松表述已撤销，后续分镜默认执行合并规范。只有用户当次明确要求例外时才可放宽；现存项目稿件不因技能更新被自动重写。
