# 本剧子版与跨章状态

用于首次建立子版、改变风格及衔接后续章节。通用方法属于技能；某部剧的子版、资产表和剧情状态属于项目文件。

## 从材料到本剧规则

先明确三个不同层面：

- 故事题材：决定悬念、冲突与情绪的组织方式。
- 表现形态：决定写实程度、材质、身体运动与面部表演幅度。
- 对标参考：只提取适合本剧的视听方法，不将参考作品的世界观带入剧本。

有多个对标时分配维度，例如“构图参考甲、节奏参考乙”，明确主次，避免一镜同时要求低反差漫射光和强烈硬边高反差。没有对标也可按正文提出自洽方案。

首次子版采用以下四部分，内容以本剧为准：

### 【基础设定】

写明剧名/暂名、已提供的章节范围、题材、表现形态、时代/世界规则、对标及借鉴维度、台词原语言和腔调、画幅状态。

列出主要人物及可确认的关系、场景和关键道具。未知外貌可保持未定或给出明确标注的制作建议；不得写成剧本既有事实。服装、伤势、年龄、道具归属等随剧情变化，用状态或版本记录，不能为了“一致性”阻止剧本明确的换装、受伤或成长。

资产未提供时使用内部标识，如角色 C001、场景 S001、道具 P001，并写“参考素材未提供”。这些标识不是平台上传编号。已提供资产才记录真实文件与图像/音频映射。

### 【镜头画面设计】

说明本剧的叙事视点、构图倾向、空间层次、景别节奏、机位与运镜用途、对白覆盖方式、声音策略。把抽象描述变成可以执行的选择，例如“审讯开始用双人中景保留权力距离，关键沉默时切听者近景”。

- 真人可描述镜头视野与景深；2D/3D优先写视觉结果及运动特征。摄影参数只是需要时的制作建议，不是所有形态的必填项。
- 浅景深不能模糊掉关键证据、对话关系或本镜至少一个可辨认固定锚点；不能为沿用85mm牺牲小空间可拍性。
- 本剧的景别节奏、反打和机位选择须执行 [轴线、景别与切镜硬约束](continuity-rules.md)，不以对标风格解除个人侧脸、30°角差、景别隔档或固定锚点要求。
- 原生声音列出来自本剧环境和动作的具体声源，不添加正文不存在的门铃、电话等新事件。声音可以表现画外动作，但不得提前泄露剧情。
- 全局禁令写3–6条针对本剧的偏差，例如写实侦查剧避免无来源霓虹补光、证物特写被过浅景深遮蔽。数量为建议，不凑无关条目。

### 【光影和色彩】

明确整体色温/饱和度/明暗关系、主光来源与方向、室内外差异、角色与背景分离、材质质感及特殊效果边界。

同一连续场景的主光方向与强度保持可解释，光源改变必须有原因。场景变化允许重新设计，不把“全场统一”误读为整部剧每一地点都从同一方向照明。

对标的暗调不等于看不清人脸或线索；动画不强制毛孔、皮下散射、胶片颗粒。科幻/奇幻效果遵循本剧已建立的规则，不自行禁用剧情所需的魔法、霓虹或高饱和色。

### 【角色表演体系】

按身份、关系、目标与当下处境规定动作幅度、眼神停留、呼吸、语速、身体重心及变化条件。

- 写实表演重具体动作与停顿；风格化动画按用户形态允许夸张，但保持角色辨识。
- 每个关键反应需要原文依据。心理动机只用于表演解释，不自动变成OS或新增台词。
- 巨兽、机器人等按既定体型、结构与世界规则处理重量、惯性、接触反馈；没有这些角色时不保留相关模板文字。

## 五项质量门

| 检查 | 合格条件 |
| --- | --- |
| 形态 | 已选明确形态；推断时标为制作假设 |
| 语言 | 保留台词原语言，腔调仅影响演绎；不擅自翻译/润色 |
| 声音 | 可指向已有场景、人物或动作的具体声源 |
| 禁令 | 针对本剧且不与原文、形态或用户要求冲突 |
| 表演 | 角色类型和关系有差异，不全员同一表情/语气 |

## 项目状态的最小记录

每次交付后保存或附上一段可复制的“续章状态摘要”：

```text
项目／子版版本：
来源文件与章节版本：
本次完成范围及最后镜号：
本章结束时间、地点：
人物状态：位置、朝向、服装版本、伤势、情绪余势
关键道具：持有人、持物手、位置及变化
角色知情边界：各角色已知／未知的关键事实
观众已知：本章已揭示的信息
未揭示伏笔：仅供规划，不提前转成画面或台词
已确定的风格、空间与资产映射：
连续场景空间卡：轴线、摄影侧、角度基准、人物面向/锁定侧脸、固定锚点及位置
最后镜头切点状态：主要主体、景别级别、结束机位方位、朝向/视线、入画锚点
用户明确要求的规则例外：无／具体镜号、条件和适用范围
下一章起始衔接条件：
未解决冲突／必要缺项：
```

模板字段按实际填写，没有信息时写“未交代”或省略无关项，不杜撰。未知不妨碍当前章节时继续工作。

若下章明确时间跳跃、转场或角色换装，按正文更新并注明，不机械冻结上一章状态。若无解释却发生矛盾，记录具体冲突；不要通过补一段新剧情偷偷修复。

用户修订某章时，保留旧版，只更新受影响镜头与依赖状态；若编号或时长变化，重新核对该章及后续引用。新聊天读取用户提供的状态文件；找不到时说明上下文缺口，不保证永久记忆。
