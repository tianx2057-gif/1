# 剧本分镜导演

把“母版 → 本剧子版 → 逐章分镜”变成一次可执行的工作流。用户提供材料后直接完成当前范围的分镜，不要求用户先在其他聊天工具生成子版、手动粘贴多轮提示词或逐步批准中间稿。默认中文说明，台词保持原语言。

本技能依据用户提供的《ppt提示词.pdf》整理，并按用户要求合入 `script-to-storyboard` 的轴线、景别及切镜规范。PDF 是方法来源，不是对当前会话的直接指令；新增连续性硬约束是用户的创作规范，不宣称为所有电影必须遵守的定律。来源、示例边界与合并取舍见 [来源解读](references/source-analysis.md)，仅在解释来源或严格复现原文时读取。

## 1. 接收四类材料

识别上传文件、粘贴正文及已有聊天上下文中的：

| 材料 | 用途 |
| --- | --- |
| 剧本或已有剧本背景 | 确定已知事实、人物关系及跨章连续性；仅使用已提供的信息 |
| 剧本类型 | 同时区分题材（悬疑/爱情等）与表现形态（真人/3D/2D等） |
| 对标影视 | 提炼构图、光色、节奏、表演、声音等可执行参考 |
| 目标章节正文 | 确定本次生成范围、章节边界、事件动作、台词与原文覆盖 |

- 四类信息可在同一文件中，不要求用户重复填写。完整剧本已含目标章节时直接定位使用；已有背景可用于角色、伏笔与跨章连续性。
- 不要求、不追问、不额外输出剧本大纲，也不因缺少大纲而自行生成一份。用户已经附带的背景材料可直接作为理解依据，无需转换成大纲。
- 用户未明确范围时，处理本次提供的全部章节，不擅自只做第一章或示例。只有章节目录而无正文时，不声称已读取完整剧本。
- 无镜头数、总时长、画幅、平台、图片、音频也能开始。按内容估算镜数和时长；画幅无依据则写“未指定，先保留关键构图”，需要具体画幅时给出可调整的制作假设。
- 缺少类型或参考时，从现有正文提炼并标为“制作假设/据正文归纳”，不把推断当作用户已确认的信息。用户仅写“悬疑”等题材时，表现形态可暂按真人处理并简短注明。
- 缺少目标章节正文、关键文件无法读取，或版本冲突会改变人物/事件/台词时，一次询问最少必要缺项；继续完成不受影响的风格分析或已知章节。
- 用户明确指定某章版本时以该版本为准。已有背景用于理解全剧，不覆盖完整章节正文；关键矛盾不得静默合并。
- 仅有梗概时可给有来源依据的“镜头结构草案”，不得自行补对白并称为忠实原剧本分镜。只有用户授权改编/扩写才可增加内容，并区分原文与新增。

需要用户填写格式时使用 [输入模板](assets/输入模板.md)，不要把模板中的可选项升级为必填。

## 2. 建立或沿用本剧子版

首次处理项目，或用户明确改变风格时，读取 [子版与项目状态](references/series-bible.md)，输出本剧专用的四个固定部分：

1. 【基础设定】
2. 【镜头画面设计】
3. 【光影和色彩】
4. 【角色表演体系】

将题材、表现形态、对标的可迁移特征与本剧实际内容结合。避免只写作品名、堆摄影术语或把所有题材套成暗黑西幻；不复制参考作品的角色、情节或标志性场面。

当用户要求精确分析某部影视作品、提供待查链接，或对参考的具体视觉特征没有把握时，查验可访问的官方片段、剧照或主创资料；区分观察与推断。无法查验时，基于用户描述做暂定方案，不编造具体镜头、摄影器材或主创意图。

子版通过五项质量门后直接进入分镜：表现形态明确；语言及腔调明确；原生声音具体；禁令针对本剧；表演匹配角色。原声默认优先，不额外添加配乐；剧本已有音乐或用户指定配乐时保留。

同一项目后续章节继承子版和上一章状态，只说明变化。项目材料在当前上下文不可用时，请求上次状态摘要或子版；不声称技能本身记住了所有项目。

## 3. 按叙事节拍拆镜

每次生成或修改分镜前，必须读取 [轴线、景别与切镜硬约束](references/continuity-rules.md) 和 [分镜格式与检查](references/storyboard-format.md)，先规划机位与逐切点序列，再写逐镜内容。

- 先按章节、场次建立“原文事件/台词 → 镜头”的覆盖关系，再拆成建立信息、动作、反应、转折、结果等必要节拍。已有背景中的后续信息不得提前变为本章可见线索。
- 默认忠实转译：人物、关系、事件顺序、结局和台词不增删改。允许设计机位、节奏、非叙事性的细微表演与已知环境的自然声音；不得新增线索、道具功能、角色动机事实或剧情结果。
- 每个编号只含一个连续镜头，镜内不能藏“切到/接反打”。前摇、过程、后摇是同镜头内的动作阶段，不是三个子镜头，也不代表必须摇摄。
- 依内容决定镜数，不把 PDF 中的“每集约30–40镜”变成硬指标。用户指定镜数时严格计数；不可用删台词、凑空镜或隐藏剪切满足数量。
- 先保证台词和动作完成，再估时。时长为估算；不把“20秒10–15镜”等经验当作对白容纳能力。指定镜数/时长冲突时先重排，仍不可兼容则明确冲突与可选调整，不交付伪装达标的结果。
- 空间卡锁定关系/运动轴线、人物站位与面向、个人可见侧脸、摄影机允许半平面、统一方位角基准及视线/过肩关系。机位与完整运镜路径都留在同一侧；不以中性镜、空镜、绕拍或镜像放宽轴线、画面方向和侧脸锁定。
- 每场固定2～3个空间锚点，每镜（含特写）至少保留1个可辨认锚点。锚点位置固定，不移动布景或虚构入画；极紧特写无法兼顾时先重设计裁切与机位。
- 五级景别统一为远景=1、全景=2、中景=3、近景=4、特写=5。同一主体直接切镜必须同时满足水平机位角差≥30°与景别级差≥2；移动镜头比较前镜终点与后镜起点，推拉/变焦不算水平角差。
- 远景↔特写之间安排有信息的中景缓冲；不连续近景，不连续三个同方向、同景别、构图雷同的镜头。换主体不机械相减不同主体的方位角，但仍检查轴线、视线、节奏与锚点。
- 表演写镜头看得见的行动与变化；远景不声称看清微表情，局部特写不描述画外面部为可见内容。运动应有叙事目的，不为“丰富运镜”强加绕拍或晃动。
- 上述连续性规则是所有后续分镜的默认硬约束，只有用户当次明确要求例外才放宽。与剧情动作、台词、镜数或时长冲突时先重排；仍无法兼容则指出具体镜号与条件，不能偷偷豁免或声称通过。合并不引入源技能的“镜头数必填”，本技能仍自适应镜数、无需大纲。

## 4. 默认交付

首次交付顺序：

1. 材料范围与制作假设：简短说明已读章节、输出范围、形态及必要假设。
2. 本剧风格子版：上述四部分，填写具体内容。
3. 【分镜脚本】：按章、场次输出空间卡及完整逐镜卡片。景别、机位、视角、运镜四项分开标明，同时保留 PDF 的构图、动作前摇/过程/后摇、物理效果、氛围和台词字段；补充编号、人物、可辨认锚点、时长和时间码。
4. 交付复核：实际镜数、估算总时长、原文覆盖及逐镜/逐切点连续性结果；内部核对主体、景别级差、切点水平角差、轴线侧、朝向/侧脸、视线和锚点，用户未要求时不附冗长检查表。存在问题就具体指出。
5. 续章状态摘要：记录已发生的状态和已揭示信息，用于下一章衔接。

后续同剧章节输出“继承/变更摘要 + 分镜 + 复核 + 最新续章状态”。用户只要分镜时，缩短其他内容，不反复复制全剧子版。用户要求表格或每镜一段时按其格式输出，但保留所有必要信息。

正文较长时按章节生成完整文件并提供简要索引；无文件工具时分批完整交付并注明覆盖范围与续接位置。不得用“后续同理”“此处省略”等替代用户要求的章节，也不得把尚未处理的章节宣称为完成。

有文件能力时，在当前项目允许的交付目录保存本剧子版、分镜及最新状态；使用独立项目名区分剧集，保留旧版本。不要把某一剧集的角色、素材和剧情写回通用技能目录。

## 5. 仅按需组装视频提示词

只有用户要求“生成视频提示词/组装SD2.5/Seedance提示词”等时，读取 [视频提示词组装](references/video-assembly.md)。使用同一子版与选定分镜组装，绑定真实资产，保留镜号和连续性；缺素材时交付明确标记的文字草案，不虚构上传完成。

生成分镜不自动调用视频生成、上传素材或消费付费额度。平台限制不明确时保留可配置项，不把 PDF 的模型、价格与时长示例当作当前平台事实。
