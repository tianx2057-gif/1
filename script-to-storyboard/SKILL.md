# 定量分镜与表演设计

将原剧本转换成可以拍摄、可以表演的分镜。用户指定的镜头数量、原文剧情与台词、空间连续性、合理时长是共同约束。默认中文输出，优先遵循用户提供的分镜格式。

## 输入与缺失信息

- 读取上传或粘贴的剧本；先确认场景、人物、事件顺序和对白。无法读取文件时明确说明，请用户提供可读正文，不能伪称已读。扫描件识别出的不确定人名、台词须标记确认。
- 必需输入是剧本与正整数镜头数 N。缺少任何一个时只询问缺项；可以先分析已有剧本，但不要擅自把示例数字当目标数量。
- 可选输入包括总时长、单镜时长范围、画幅、风格和平台限制。缺失时根据内容估时并标注，不为这些可选项阻塞工作。
- 区分全片共 N 镜与每场 N 镜。通常将“生成 N 个分镜”理解为全篇总计 N 镜；有实质歧义才确认。
- 不默认添加图像资产、视频生成提示词、配乐方案或多集改编。用户另有要求时再扩展。

## 拆镜与数量

先梳理每场的叙事节拍：信息建立、行动、冲突、情绪变化、反应和结果；再分配镜头预算，总数必须等于 N。

- 一个编号是一段连续拍摄。镜头内部可以有连续动作、摇移或焦点转移，不能写“切到”“接反打”等隐藏剪切；发生剪切必须另编号。
- 按事件重要性、对白长度和情绪转折分配镜头，不均摊，也不靠无意义空镜凑数。可将同一连续空间的动作合并为合理长镜头；新增反应镜头须服务于理解或情绪。
- 不为了满足数量删掉关键因果、人物、动作或未经允许改写对白。极少镜头无法覆盖互不连续的场景，或指定总时长无法容纳原文时，说明具体冲突并询问应放宽哪项，不提交伪装合规的成品。
- 修改局部镜头时重新核对总数、时长、前后动作及空间关系；原编号优先保持，需重排则统一编号。

## 180°轴线与侧脸锁定

每个场景先建立简短的空间连续性卡，再写镜头。卡片至少包含：轴线依据、人物位置、面向、摄影机允许区域、各人物允许露出的侧脸、视线对象及重要道具位置。

- 双人交流以两人连线为主轴；行走、追逐以运动方向为主轴。多人物场景先确定主互动关系与其余人物的位置，不能每次换说话人就无说明另立轴线。
- 所有机位与运镜路径留在同一侧半平面，不越轴、不跳轴、不以绕拍或中性镜头作为换侧借口。新场景可以建立新的空间卡；同一场景默认保持不变。
- 同时实行更严格的个人侧脸锁定：一旦确定拍摄某人的左脸或右脸，同一连续场景保持该侧；不自动改成另一侧或正面。人物转头、转身也要检查是否破坏锁定；剧本必须转身而导致冲突时提出局部处理或询问，不能偷偷改变朝向。
- 人物自身的左脸/右脸与画面的左/右是不同概念。先根据俯视空间关系判断可见侧脸，再描述画面朝向；不能仅凭“面向画右”机械推导侧脸。
- 每镜明确主体面向画左/画右、视线指向；需要时补充朝前景/后景及角度。画左/画右始终按观众观看画面定义。特写仍沿用前镜的朝向与视线关系。
- 正反打保留双方相反的视线方向，不把两人都写成朝同一画外方向看向彼此。保持出入画方向、坐站位置、持物手和动作衔接。
- 过肩不能只写“过肩镜头”。必须明确前景人物位于画左还是画右、背对机位、肩背遮挡位置，以及后景主体的位置、朝向和对焦对象。肩背人物也计入出场人物。
- 过肩中前景人物可以不露脸，但后续露脸仍须保持其锁定侧。不要为了凑齐侧脸字段声称背对机位的人正露着脸。
- 避免含混的“左侧机位”：写“位于甲的左前侧、主轴既定摄影侧”等可定位表述。推拉摇移必须注明方向与终点，整个路径保持在许可侧。

可用的双人空间卡示例：俯视图中甲在西、乙在东，两人相向；摄影机始终在两人连线南侧。甲朝东、可见右脸，乙朝西、可见左脸；在该侧的对话构图中甲面向画右、乙面向画左。机位靠近甲拍乙时，甲的肩背在画左前景，乙在画右后景；机位靠近乙拍甲时则相反。此示例只适用于这一组明确站位，不作为所有场景的固定模板。

## 四个镜头限定词

每镜分别写出以下四项，不能合并成一串无法区分的术语：

- **景别**：远景、全景、中景、近景、特写等，并明确截取范围或主体。景别应承载该镜的信息重点。
- **机位**：摄影机相对人物的位置、既定轴线侧、人物在画面的位置与朝向、可见侧脸；过肩补齐前后景人物及肩背关系。
- **视角**：平视、俯视、仰视等观看角度；需要主观或客观视点时另补，不能用“左脸”代替视角。
- **运镜**：固定、缓推、拉远、横移、跟拍、摇镜等。固定镜头明确写“固定”；移动镜头写起点、方向、终点及目的。焦点转移可另补，不能代替摄影机运动描述。

## 台词与可执行表演

- 有台词必须写出说话人和原句；无台词写“无”。区分现场对白、画外音 VO、内心独白 OS。原剧本未出现的内心活动只能作为表演动机，不能擅自编成可听见的独白。
- 长台词跨镜按原文顺序在自然停顿处分段，注明续接，确保无遗漏和重复。反应镜头里的画外对白照常标明说话人，不能改算成画面人物开口。
- 每镜表演写出可观察的面部细节、肢体动作、心理动机和语气情绪。使用“情绪触发→具体变化→动作或台词→余韵”的节拍组织，需要多少写多少，避免互相冲突的表情堆砌。
- 面部写眉、眼、嘴角、下颌、呼吸等具体变化；肢体写力度、方向、速度、作用对象及结束姿态。使用“戳、攥、甩、扣、推、缩”等准确动词，避免只有“生气地指着”。
- 例如外放愤怒可写：“眉头紧皱，双眼微眯，下颌绷紧；身体前倾，食指朝对方胸前猛戳一下并悬停；为逼对方认错，以压不住的怒吼说出台词，句尾喘息。”这是对外放愤怒的示例，不把所有愤怒都写成怒吼；压抑愤怒可用压低声音、咬字发紧、攥拳和短促呼吸。
- 心理动机必须有剧本依据；推断仅用于驱动表演，不增添未经交代的人物关系或剧情事实。无对白镜头的语气字段写“无发声”，仍可描述情绪与呼吸。
- 表演须符合景别可见程度。远景主要写姿态、移动和节奏，不声称能看清眼睑细节；手部特写将面部注明“画外”，通过手部动作表达情绪。只写镜头能呈现的细节，不强行让眉眼和手指都进入脸部特写。

## 时长估算

每镜写明确秒数和连续时间码，标注全片预计总时长；无实测音频时说明属于拍摄/朗读估算。

- 先估台词，再估动作、情绪反应、运镜与必要停顿。中文初估可用每秒约3–4个口语字，急促对白约4–5个，迟疑或强情绪约2–3个；数字、英文、专名按实际读音估算，不将这些数值当固定标准。
- 把停顿、换气、犹豫与哭喊计入。怒吼未必更快，不能为了短时长把长句一口气塞进镜头。
- 同时发生的说话与动作按较长者估时；先后发生的动作则相加。不能把所有动作时长机械叠加，也不能把先走近再说话当作完全重叠。
- 时长服从内容。反应镜可短，长对白或复杂动作可长，不强制每镜等长。单镜超过用户/平台限制时在既定 N 内重新分配；无法兼容时说明冲突。
- 指定总时长 T 时核对每镜合计恰为 T，并保证内容可完成。未指定 T 时给出合理合计，不虚构用户要求的总时长。

## 默认输出

先给一行摘要：目标 N 镜、实际 N 镜、预计总时长、时长是否为估算。然后按场景给简短空间连续性卡，再逐镜输出下列字段。没有用户指定格式时用分镜卡片，避免超宽表格使表演难以阅读。

### 镜头01｜场景｜时长 X 秒｜00:00–00:XX

- 景别：
- 机位：
- 视角：
- 运镜：
- 出场人物：列出可见人物，包括肩背/局部；仅声音出现者另列。
- 画面与动作：按发生顺序描述主体动作和必要环境信息。
- 表演：面部；肢体；心理动机/情绪；发声语气。不可见部分标明，不用抽象情绪词代替可观察动作。
- 台词：人物名【语气；对白/VO/OS】：“原文台词”；无台词写“无”。

不要将模板空字段留在正式交付中。结尾用一句话报告数量、总时长及连续性复核结果；若存在未解决冲突，明确列出，不能宣称通过。

## 交付前复核

1. 编号从01到N连续，无隐藏剪切、子镜头或未计数的转场。
2. 原文关键剧情与所有台词完整；跨镜台词按顺序拼回原句，未重复、未擅改说话人。
3. 四个限定词、出场人物、表演、台词和时长逐镜齐全；术语与画面可执行且相互一致。
4. 逐镜对照空间卡检查摄影机位置与移动路径、面向、可见侧脸、视线、过肩关系以及道具和动作接续，不以“遵守180°”一句话替代检查。
5. 台词和动作能在分配时长内完成，时间码无缺口或重叠，秒数合计正确，满足用户给定总时长及单镜限制。
