# 分镜生成大师

将上传或粘贴的剧本转换为指定数量的中文分镜脚本。

## 功能

- 按指定镜头数量拆分剧情，保留关键动作和原文台词。
- 每镜包含景别、机位、视角、运镜、出场人物和时长。
- 细化面部表情、肢体动作、心理动机及发声语气。
- 以180°轴线为基础，保持人物朝向、视线和可见侧脸连续，明确过肩构图。
- 按对白、动作与停顿估算单镜时长，并复核全片时间码。

## 后续分镜默认遵守的衔接规范

**机位不过轴、同主体切镜角度至少30°、景别隔一档、两极插中景。**

这些是本技能采用的固定创作要求；除非用户明确另作要求，每次生成和修改分镜都执行：

- 摄影机与运镜路径保持轴线同侧，锁定屏幕方向及人物可见侧脸；不能仅凭夹角小于180°判断没有越轴。
- 同主体相邻镜头直接剪切时，水平机位角度差至少30°，并且景别至少相差两级；推拉、变焦和裁切不替代方位角变化。
- 五级景别为远景、全景、中景、近景、特写。“隔一档”例如远景→中景、全景→近景、中景→特写；不采用同主体的相邻一级硬接。
- 远景与特写之间插入有内容的中景，计入镜头总数和时长；不连续堆叠近景，不连续安排三个同方向、同景别的雷同镜头。
- 每场选定2～3个固定空间锚点，每镜至少保留一个可辨认锚点。
- 切换主要主体时不机械套用同主体角差，但继续检查轴线、视线、连续近景及构图变化。无法兼顾硬约束时明确指出冲突，不自行放宽。
- 交付前逐切点检查；中性镜头等越轴补救方式仅用于用户明确要求的既有素材修复，不作为新分镜越轴的例外。

上述规则是用户指定的创作规范，不宣称为所有影视剪辑的普遍定律。默认输出 Markdown，每个镜头一个完整段落，包含人物、四个限定词、表演、台词、时长及入画锚点。

## 文件

技能主体位于 [script-to-storyboard/SKILL.md](script-to-storyboard/SKILL.md)。这是供支持技能指令的 AI 助手读取的 Markdown 技能，不是独立运行的程序，也不包含视频生成服务。

## 使用示例

在已加载此技能的助手中提供剧本，并输入：

> 使用 $script-to-storyboard，把这份剧本生成40个分镜，保留全部台词，根据对白和动作合理安排每镜时长。

需要整段格式时，可追加：

> 输出 Markdown 文档，每个镜头为一个完整段落，依次包含人物、景别-机位-视角-运镜、动作表演、台词及时间码，方便复制到飞书文档。

可同时指定总时长、单镜时长范围、画幅或输出格式。无法同时满足数量、剧情和时长时，技能会说明约束冲突。

本仓库包含技能与使用说明，不包含用户剧本、角色参考图或生成图片。时长和空间连续性仍需结合实际场景、演员试读及拍摄条件复核。
