# 剧本分镜导演

融合「分镜生成大师」的轴线、景别与镜头衔接规范，以及「母版 → 本剧风格子版 → 逐章分镜」工作流。

推荐使用合并版 **`series-storyboard-director`**。提供剧本或已有背景、剧本类型、对标影视、目标章节正文，即可建立本剧视听风格并生成完整分镜。**不需要剧本大纲，镜头数量可由内容自动估算。**

## 输入与输出

输入可以来自附件、粘贴正文或已有聊天上下文，已包含的信息不用重复填写。镜数、总时长、画幅、参考图片和音频都是可选项；明确指定镜数或时长时，会检查数量、台词、动作与连续性是否能够同时满足。

首次输出本剧风格子版、场景空间卡、逐镜分镜、实际镜数与估算时长，以及续章状态。后续章节沿用已建立的风格与状态。

每镜独立写出景别、机位、视角和运镜，并保留构图、动作前摇／过程／后摇、物理效果、氛围、台词与时间码。支持逐镜卡片，也支持每镜一个完整段落或用户指定的表格格式。

## 默认执行的连续性规则

**机位不过轴、同主体切镜角度至少30°、景别隔一档、两极插中景。**

- 摄影机及运动路径始终保持既定轴线同侧；锁定人物朝向、视线、可见侧脸与屏幕方向。
- 同主体相邻镜头直接剪切，水平观察方位差至少30°，并且景别至少相差两级；两项同时检查，推拉、变焦和裁切不能替代方位角变化。
- 五级景别：远景=1、全景=2、中景=3、近景=4、特写=5。“隔一档”指级差至少2，例如全景↔近景、中景↔特写。
- 远景与特写之间安排有叙事内容的中景；缓冲镜计入镜数与时长。不连续堆叠近景，不连续安排三个同方向、同景别、构图雷同的镜头。
- 每场确定2–3个固定空间锚点，每镜至少出现一个可辨认锚点，特写也需检查。
- 过肩镜头写清前后景人物、肩背位置、主体朝向及对焦对象。切换主体不拿不同人物的机位角度相减。
- 交付前逐切点检查；遇到规则与原文动作、指定镜数或时长冲突，先重排镜头，仍不可兼容时明确说明，不悄悄放宽。

这些是用户指定的默认创作规范，不宣称是所有影视剪辑的普遍定律。只有用户明确要求例外时才调整。

## 使用

将整个 `series-storyboard-director` 文件夹放到你的技能目录，保留 `SKILL.md`、`references/`、`assets/` 和 `agents/` 的相对结构。

```text
使用 $series-storyboard-director，为以下章节生成分镜。

剧本或已有背景：见附件
剧本类型：题材 + 表现形态
对标影视：作品名称或参考方向
目标章节正文：……
```

可以补充：

```text
本章指定30镜，英文台词逐字保留。
每镜写成一个完整段落，方便复制到飞书。
```

同一聊天续做下一章时，直接上传新正文并要求沿用本剧子版。新聊天请一并提供已有子版和续章状态，避免角色与道具状态丢失。
